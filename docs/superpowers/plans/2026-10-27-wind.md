# Wind pilot Implementation Plan

> **For agentic workers:** use superpowers:executing-plans inline. Steps use checkbox syntax for tracking.

**Goal:** reproducible historical decision-time wind forecast comparison.
**Architecture:** immutable real-data gzip snapshot → FastAPI selection/metrics → React dashboard; same-origin production serving.
**Tech stack:** React, TypeScript, Vite, Recharts, FastAPI, httpx, pytest, Docker.
**Spec:** ../specs/2026-10-27-wind-design.md

## Global constraints
Only Elexon FUELHH WIND and WINDFOR. January 2026 decisions, next-day delivery. Configurable cutoff, default 10:00 Europe/London. No synthetic production results. Scope fits a 16-hour assignment.

## Review focus
Latest eligible null must not resurrect an older valid forecast. Conflicting tied publications must be excluded. Hourly forecast gaps must remain visible. Failed refresh must preserve cache. Stale browser requests must never replace current settings.
